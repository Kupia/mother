# Поздравление Татьяны с днём рождения (26.11)

Статический сайт без сборщика: HTML, CSS и JavaScript. Главная страница — вертикальная карта-маршрут на тему «моря и вода»: страница прокручивается сверху вниз, следы босых ног «достраиваются» при нажатии на место, после чего открывается галерея фотографий.

**Все требования и согласованные решения собраны в проектном скилле:** `.opencode/skills/birthday-map/SKILL.md`. Перед изменениями открывай его, после новых требований — дополняй раздел «Журнал решений».

## Что уже есть

- Вертикальная карта (`viewBox 0 0 1000 3600`) с абстрактными берегами и лёгкими волнами. Пятен ровно столько, сколько локаций: все они тёплого песочного цвета (`#f2ddb8`), но **разной формы с изрезанными берегами**, чтобы выглядели как границы островов; каждый пин стоит на своём пятне. Фон карты — снежно-голубой: насыщенный сверху и постепенно темнеет к низу, создавая ощущение глубины; в глубине плавают две полупрозрачные медузы. На каждом острове — узнаваемый силуэт места (маяк, велосипед, три озера, вантовый мост с прямыми тросами, яхта, сидящий Будда); значки не пересекают следы. В Трёозерье — просто три озера, залитые цветом морской воды. Следы — тёмно-песочного цвета (`#a4734a`), темнее островов, но без «трубы», текстур и валиков. Стиль в остальном минималистичный.
- Шесть точек маршрута: Сахалин → Минское море → Треозерье → Владивосток → Кипр → Таиланд. Новые места дописываются в конец массива.
- Три круглые иконки-кнопки в шапке: **крабик** — волна поднимается примерно на треть экрана, ненадолго задерживается и отступает; из-под неё появляются маленькие рисованные крабики — все розовые, строго на уровне линии воды и никогда выше — и разбегаются в стороны (следы при этом остаются); **искра** — конфетти; **девушка на сапе** — проплывает слева направо по экрану.
- Заголовок страницы в стиле сайта: «Твое большое морское путешествие».
- Изначально следов нет. На островах написаны названия (без плашек и эмодзи) с небольшой красной точкой слева. Клик по Сахалину ведёт следы из-за верхнего края карты; дальше следы достраиваются от последней посещённой точки до выбранной и приходят прямо к названию, затем открывается панель с галереей.
- Панель с 4 фото-заглушками на место; клик по плитке открывает просмотр со стрелками ← → и закрытием по Esc / клику по фону. Панель выезжает **с противоположной стороны от островка**: левый остров → панель справа, правый → слева. Фон почти не затеняется (дымка ~8%, без blur), карта остаётся видна; на телефоне панель по-прежнему выезжает снизу.
- В конце страницы по центру — надпись «Куда дальше?»; по нажатию раскрывается текст поздравления от семьи.
- Адаптив: на узком экране галерея выезжает нижней шторкой; карта сохраняет пропорции и на телефоне, и на десктопе.
- `prefers-reduced-motion`: движение отключается, если так настроено в системе.

## Как запустить локально

Достаточно открыть `index.html` в браузере — сервер не нужен.

## Как добавить или изменить место

Всё редактируется в одном файле — `data/places.js`.

```js
{
  id: "sakhalin",             // латиницей, без пробелов — имя папки с фото
  city: "Сахалин",
  country: "Россия",
  pos: { x: 337, y: 320 },    // координаты в системе 1000 × 3600
  title: "Тихий берег",
  caption: "Подпись-воспоминание",
  photos: [ /* ... */ ]
}
```

Порядок элементов в массиве задаёт порядок следования точек по маршруту. `pos.x` — от 0 до 1000 слева направо, `pos.y` — от 0 до 3600 сверху вниз. Чтобы добавить новое место, допиши объект в конец массива и задай ему следующую позицию ниже по карте. Если новых точек не хватает высоты, увеличь `viewBox` в `index.html`, `aspect-ratio` у `.map` в CSS и делитель `36` в `js/main.js` (строка с `--y`).

## Как заменить заглушки на настоящие фотографии

1. Положи оптимизированные копии в `assets/photos/<id-места>/`, например:

   ```text
   assets/photos/sakhalin/01-thumb.webp   # 640 px, 60–100 КБ — для плитки
   assets/photos/sakhalin/01.webp         # 1600 px, 200–400 КБ — для полноэкранного просмотра
   ```

2. Добавь к нужному фото в `data/places.js` поля `thumb` и `full`:

   ```js
   { alt: "Берег и скалы",
     thumb: "assets/photos/sakhalin/01-thumb.webp",
     full: "assets/photos/sakhalin/01.webp" }
   ```

## Как опубликовать

Репозиторий: `https://github.com/Kupia/mother.git`. Сайт опубликован: **https://kupia.github.io/mother/**.

- Исходники лежат в ветке `main`, деплой идёт через `.github/workflows/deploy.yml`.
- GitHub Pages включён с источником **GitHub Actions** (`Settings → Pages → Build and deployment`).
- Каждый `push` в `main` автоматически перевыкладывает сайт. Локальные правки перед публикацией можно проверить через `index.html` — сервер не нужен.

## Важное про фотографии с Яндекс.Диска

Публичная ссылка «Поделиться» ведёт на страницу-просмотрщик, а не на сам файл. В `<img src>` она не сработает — оригиналы остаются на Диске, а в репозиторий кладутся оптимизированные копии по схеме выше.
